HELP & SUPPORT

让喜欢的画面，轻松留在桌面。

从一幅内置画布开始，无需账号、登录或导入文件。

第一次使用

  1. 在“动态画布”中点击一个场景，右侧立即预览。挑选不会改变桌面。
  2. 点击“放大预览与调整”修改速度、色相、亮度、密度或画面尺度。
  3. 满意后点击“应用到桌面”，或按 ⌘↩。各场景自动保留各自的参数。
  4. 关闭控制面板后，壁纸继续运行；从菜单栏图标或 Dock 重新打开。关闭壁纸开关或退出幕灵，即显示原系统壁纸。

收藏与轮换

点击卡片上的爱心收藏场景。“最近使用”只记录实际应用过的画面。收藏至少 2 个动态场景后，可在右侧主动开启收藏轮换，选择 5、15、30、60 或 120 分钟，以及随机或顺序播放。

轮换使用每个场景保存的参数，后台切换不覆盖正在编辑的预览。手动暂停、休眠、关闭壁纸或所有桌面暂停播放时冻结计时；手动应用其他壁纸会停止轮换。菜单栏可切换下一张收藏。轮换暂不包含 PLY 模型。

常见问题

壁纸静止了，或预览暂停？

先看侧栏的播放状态，再检查右侧“节能”设置：全屏、桌面不可见、电池供电、系统低电量、温度或“减少动态效果”都可能影响播放。预览旁的暂停按钮仅控制预览，侧栏暂停控制桌面。系统“减少动态效果”默认受到尊重，请按自己的需求决定是否调整。

如何导入自己的 3D 空间？

切换到“3D 空间”，导入或拖入外部生成的 3D Gaussian Splatting PLY。支持带高斯属性的二进制小端格式，最多 500 万点、512 MB；普通点云或网格 PLY 不适用。导入会保存副本，不改动原文件。应用本身不生成模型。

可下载我们原创的 蓝色轨道示例 PLY 体验导入。它是程序化生成的抽象高斯场景，不含照片或个人数据。

3D 模型边缘有空洞或变形？

单图生成的 3DGS 更适合轻微视差。先降低运动幅度，再适度放大画面。带相机参数的文件通常更容易获得正确视角；必要时在生成工具中调整后重新导出。

可以使用自己的 HTML / CSS / JS 吗？

在“动态画布 → 自定义”中创建场景，或导入 UTF-8 HTML / 场景 JSON。提供无依赖、Three.js、Vanta.js、particles.js 等随包库。需要粘贴已编译的代码，外部贴图和其他依赖须先整理。暂不直接导入远程 Pen 链接、ZIP、npm 工程、React/JSX 或 SCSS。请只使用自己有权使用的作品。

场景在隔离 iframe 中离线运行，没有原生命令桥或远程网络连接。速度、暂停和亮度由应用接入，其他参数需由自定义代码使用。任意第三方代码不保证直接兼容。

支持视频、锁屏和每屏不同壁纸吗？

当前版本专注动态画布和 3DGS，不支持视频壁纸或替换 macOS 锁屏，也不包含独立屏保插件。多个显示器目前共用同一壁纸，分别执行暂停策略。

如何更换图标、管理模型和备份？

在“设置与使用帮助 → 设置”选择图标配色。Finder 与安装包使用蓝色默认图标。模型卡片菜单支持改名、导出 PLY 副本和移除；右键自定义场景可编辑、导出 JSON 或移除。移除只删除应用内副本，不删除原文件。重要作品请先导出备份。

反馈与联系

请在 幕灵支持区 提交问题。建议说明 macOS 版本、Mac 型号、应用版本、场景名称、复现步骤及经脱敏的截图。

支持区是公开的。请勿上传密码、联系方式、私人照片、个人模型或其他敏感内容。请优先提供不含私人资料的最小复现步骤。

English support

Muling requires macOS 14 or later. The interface is in Simplified Chinese. Select a scene under 动态画布 (Canvas), preview it, and click 应用到桌面 (Apply) to change your desktop. Close the panel to keep the wallpaper running; quit the app to reveal the system wallpaper.

Favorite at least two canvas scenes to enable timed rotation. Local 3DGS PLY files and offline HTML/CSS/JavaScript artwork are supported. Video wallpapers, independent per-display scenes, lock screen replacement, and 3D model generation are not included.

Report issues in English or Chinese on GitHub Issues. This is a public support channel; do not include personal data or private artwork.
